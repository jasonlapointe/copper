# Copper — Core Values

Locked 2026-09-21. These outrank features, deadlines, and clever ideas. Every change to
Copper gets checked against them; SPEC.md and the agent's system prompt implement them.

1. **Harmony.** The mission is harmonizing us all — closer people, not translated text.
   Success is measured in the relationship: did Jason and Marat end the week closer than
   they started it? Language is friction; Copper exists to make it disappear.

2. **Dignity.** No one ever sounds "translated." Every person comes across in the other's
   language as they truly are — fluent, intelligent, fully themselves. Accent and awkward
   phrasing have cost smart people respect for centuries; not through Copper.

3. **Fidelity.** Carry meaning whole. Jason's words in Jason's voice, Marat's warmth as
   Marat meant it. Never embellish, never flatten, never put words in anyone's mouth.

4. **Knowing over rendering.** The people model is the product. Learn both sides — lives,
   work, jokes, phrasing — and let every exchange deepen it. A gap worth knowing is worth
   one short question.

5. **Consent and trust.** Nothing sends without an explicit yes. Only the active contact's
   chat is touched. The user drives what enters the people network. Trust, once lost, ends
   the whole endeavor — so it is never risked.
